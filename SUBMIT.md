# Submit Your Work

Deadline: **15:15 sharp**. One submission per team. You can resubmit before the deadline if you need to, the last one counts.

Work through this list in order. It takes about 10 minutes, so start at 15:00, not 15:14.

## The checklist

- [ ] **1. The brief is filled in.** Open `brief/campaign-brief.md` and check every section has real content, not template prompts.

- [ ] **2. `outputs/` has your work.** Ads, copy, creative, reports: everything your team made should be in there. If something only exists in a chat window, ask the agent to save it to a file now.

- [ ] **3. Your own agent file exists.** Look in `.github/agents/` for the agent your team built during the masterclass or after. This is worth 30 of your 100 points, so make sure the file is actually there.

- [ ] **4. Grona campaign ID copied exactly.** Copy it character for character, no spaces. Also save it into a file called `submission.txt` in the root of this folder, so it travels with your zip.

- [ ] **5. Optional but loved: export your chat.** Open the Command Palette, run **Chat: Export Chat**, and save the JSON file into this folder. It shows the judges how you worked.

- [ ] **6. Zip the WHOLE folder.** Not just `outputs/`, the entire folder. Name it `teamname.zip` using your actual team name. Keep it under 1 GB.

- [ ] **7. Upload before 15:15.** Submit here:

  https://docs.google.com/forms/d/e/1FAIpQLSdCfULmf6NYA9ZU2SKbBvE258RseOgZMJmj-AscjlYFA2SL0g/viewform

Done? Take a breath. Demos start at 15:40.
