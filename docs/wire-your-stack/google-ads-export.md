# Google Ads: Export Campaign Data

1. Open Google Ads and go to **Campaigns**.
2. Set the date range at the top right to the period you care about.
3. Click the **download** icon above the table and choose **.csv**.
4. Move the file into this folder's `data/` directory.

Then open Chat and pick **analytics-analyst**.

Try asking:

> Read data/campaigns.csv. Which campaign has the worst cost per conversion, and what would you pause first?
