# GA4: Export a Report

1. Open Google Analytics and pick your property.
2. Go to **Reports > Engagement > Pages and screens** (or any report you care about).
3. Click the **Share** icon at the top right, then **Download file > Download CSV**.
4. Move the downloaded file into this folder's `data/` directory.

Then open Chat and pick **analytics-analyst**.

Try asking:

> Read data/pages-and-screens.csv and tell me which 3 pages lose the most visitors.
