# Meta: Export Ads Data

1. Open **Ads Manager** and go to the **Campaigns** tab.
2. Set the date range at the top right.
3. Click **Reports > Export table data**, choose **.csv**, and export.
4. Move the file into this folder's `data/` directory.

Then open Chat and pick **analytics-analyst**.

Try asking:

> Read data/meta-campaigns.csv. Which ad set has the best cost per result, and what does it do differently?
